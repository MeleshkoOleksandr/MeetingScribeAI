# MeetingScribe ????

**MeetingScribe** — это высокопроизводительное приложение для автоматического стенографирования и аналитики встреч. Система использует локальный ИИ для распознавания речи и облачные LLM для создания резюме.

## ?? Дизайн-концепция: Lumina Dark
Приложение выполнено в эстетике **Modern Minimalist Dark**. 
- **Акценты:** Lime Green (Активный интеллект) и Sky Blue (Взаимодействие).
- **Стиль:** "The Silent Expert" — строгий, профессиональный интерфейс для продуктивной работы.

## ?? Основные возможности
- **Локальный ASR:** Использование `Whisper.net` (модель Large-v3-Turbo) для точного перевода речи в текст без отправки аудио в облако.
- **Интеллектуальный VAD:** Сегментация речи с помощью `Silero VAD` для корректной обработки пауз.
- **Семантическая диалогизация:** Разделение спикеров по смыслу через Gemini API.
- **Синхронизация:** Нажмите на текст, чтобы прослушать соответствующий момент аудио.
- **Экспорт:** Формирование профессиональных протоколов встреч в формате Word.

## ?? Технологический стек
- **Framework:** Avalonia UI (Кроссплатформенность)
- **Architecture:** MVVM (CommunityToolkit.Mvvm)
- **Audio:** NAudio, Whisper.net, Silero VAD
- **Intelligence:** Google Gemini API (для пост-обработки)
- **Language:** C# 12 / .NET 8 (или 9)

## ?? Установка и настройка

### 1. Требования
- .NET 8.0 SDK или выше
- Visual Studio 2022 / JetBrains Rider

### 2. Модели (Необходимы для работы)
Для работы приложения необходимо скачать и поместить в папку `/Assets` следующие файлы:
1. **Whisper Model:** `ggml-large-v3-turbo-q8_0.bin`
2. **VAD Model:** `silero_vad.onnx`

### 3. API Ключи
Для функции создания резюме и диалогизации получите ключ **Gemini API** в Google AI Studio и добавьте его в настройки приложения.

## ?? Структура проекта
- `Services/` — Ядро: работа с аудио, Whisper и VAD.
- `ViewModels/` — Логика управления состоянием интерфейса.
- `Views/` — Описания интерфейса на XAML (Avalonia).
- `Styles/` — Тема Lumina Dark и визуальные ресурсы.
