# MeetingScribe 🎙️✨

**MeetingScribe** is an AI transcription and meeting productivity suite. It automates the process of recording, transcribing, and summarizing meetings using local AI engines for privacy and cloud-based LLMs for advanced semantic analysis.

## 🚀 Key Features
- **Dual-Engine Transcription:** 
    - **Real-time:** Fast preview using `Whisper.net` (Small/Turbo models).
    - **Offline Refinement:** High-accuracy re-processing of the full recording.
- **Intelligent VAD:** Integrated `Silero VAD` for precise voice activity detection.
- **AI Studio (Review Mode):**
    - **Speaker Diarization:** Automated speaker identification using Google Gemini or OpenAI.
    - **Markdown Summaries:** Professional meeting protocols and action items generated by AI.
- **Team & Group Management:** Maintain a local database of participants, their roles, and photos to help AI identify them.
- **Agenda Import:** Automatically parse `.docx` agenda files to populate topics and participant lists.
- **Global Activity Log:** Real-time diagnostic center with exception tracking and history persistence.
- **Meeting Archive:** Comprehensive history with JSON metadata and audio recordings.

## 🛠 Tech Stack
- **Framework:** Avalonia UI (v11.2+)
- **Architecture:** MVVM (CommunityToolkit.Mvvm)
- **Audio Engine:** NAudio (16kHz Mono standard)
- **AI Processing:** Whisper.net (Vulkan/CPU), Silero VAD (ONNX)
- **LLM Integration:** Google Gemini API (Auth Keys support)
- **Document Parsing:** OpenXML (.docx)
- **Graphics:** SkiaSharp (Image processing)

## 📦 Installation & Setup

### 1. System Requirements
- **OS:** Windows 10/11 (x64)
- **Runtime:** .NET 8.0 SDK or higher. 
- **Dependencies:** [Microsoft Visual C++ Redistributable (x64)](https://aka.ms/vs/17/release/vc_redist.x64.exe) (**Required** for Whisper).
- **GPU:** Vulkan-compatible card (NVIDIA, AMD, or Intel Iris Xe) for hardware acceleration.

### 2. Required NuGet Packages
If you are setting up the project from scratch, ensure these packages are installed:
```powershell
# Core UI & Logic
Install-Package Avalonia
Install-Package CommunityToolkit.Mvvm
Install-Package Material.Icons.Avalonia
Install-Package Avalonia.Controls.ColorPicker
Install-Package Material.Icons.Avalonia

# AI & Audio
Install-Package NAudio
Install-Package Whisper.net
Install-Package Whisper.net.Runtime.Vulkan  # Use .Cublas for NVIDIA-only
Install-Package Microsoft.ML.OnnxRuntime   # For Silero VAD
Install-Package SkiaSharp                  # For Image resizing

# Tools
Install-Package DocumentFormat.OpenXml     # For Agenda Import
Install-Package Markdown.Avalonia.Tight    # For AI Summary rendering
Install-Package CommunityToolkit.Mvvm
```

### 3. AI Models Setup

The application requires specific pre-trained AI models to function. These files are large and must be downloaded manually.

#### **A. Download Whisper Models (ASR)**
Whisper models must be in the **GGML format** (compatible with `whisper.cpp`).
*   **Download Link:** [Hugging Face - ggerganov/whisper.cpp](https://huggingface.co/ggerganov/whisper.cpp/tree/main)
*   **Recommended Files:**
    *   `ggml-small.bin` (~480 MB) — Recommended for **Real-time Recording**.
    *   `ggml-large-v3-turbo-q8_0.bin` (~1.5 GB) — Recommended for **Offline Refinement**.
*   **Placement:** Move these files to `MeetingScribe/Assets/WhisperModels/`.

#### **B. Download Silero VAD (Voice Activity Detection)**
*   **Download Link:** [Silero VAD GitHub](https://github.com/snakers4/silero-vad/raw/master/files/silero_vad.onnx)
*   **File:** `silero_vad.onnx`
*   **Placement:** Move this file to `MeetingScribe/Assets/Models/`.

#### **C. Configure Model Manifest**
To make the downloaded models visible in the application settings, you must register them in `MeetingScribe/Assets/Manifests/models_manifest.json`. 

Edit the file as follows:
```json
[
  {
    "Name": "Whisper Small (Fast)",
    "FileName": "ggml-small.bin"
  },
  {
    "Name": "Whisper Large v3 Turbo (Accurate)",
    "FileName": "ggml-large-v3-turbo-q8_0.bin"
  }
]
```
*Note: The `FileName` must exactly match the name of the file saved on your disk.*

#### **D. Visual Studio Properties**
For every model file (`.bin`, `.onnx`) and the manifest (`.json`):
1.  Right-click the file in **Solution Explorer**.
2.  Set **Build Action** to `Content`.
3.  Set **Copy to Output Directory** to `Copy if newer`.

### 4. Configuration Files (Manifests)
Create these JSON files in `Assets/Manifests/` (**Build Action: Content, Copy if newer**):

**ai_providers.json**
```json
[
  {
    "Id": "Gemini_Free",
    "Name": "Google Gemini Free",
    "Url": "https://generativelanguage.googleapis.com/v1beta/models/gemini-flash-latest:generateContent",
    "Model": "gemini-flash-latest"
  },
  {
    "Id": "Gemini_Paid",
    "Name": "Google Gemini Paid",
    "Url": "https://generativelanguage.googleapis.com/v1beta/models/gemini-flash-latest:generateContent",
    "Model": "gemini-flash-latest"
  }
]
```

### 5. Secrets (API Keys)
The app stores API keys locally for security. Create a `secrets.json` file in the root of your execution folder (where the `.exe` lives). This file is automatically ignored by Git.

**secrets.json**
```json
{
  "Gemini_Free": "YOUR_API_KEY_HERE",
  "Gemini_Paid": "YOUR_API_KEY_HERE"
}
```

## ⚠️ Troubleshooting

### 503 Service Unavailable (Gemini)
If you get 503 errors on large meetings, use the **Gemini_Paid** provider or wait for the auto-retry logic to finish. The app uses 15-minute chunking to minimize this issue.

## 📂 Project Structure
- `Logic/AI/` — Implementations of `IAiService` (Gemini, ChatGPT).
- `Logic/Meeting/` — `MeetingManager` and `AgendaParser`.
- `Logic/Services/` — Audio capture, VAD, and `LogService`.
- `ViewModels/` — UI states and navigation logic.
- `Views/` — Avalonia XAML definitions and custom controls.
- `Assets/Data/` — Local storage for Participants, Groups, and Photos.
